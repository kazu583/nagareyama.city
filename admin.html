🌐 全員（他の人のスマホ・PC）にも公開する手順

追加・編集・削除した内容を全員の画面に反映させるには、下のボタンを押して最新の全記事リストをコピーし、GitHubの index.html に貼り付けてください。

STEP 1 上の青い「最新の全記事コードをコピーする」ボタンを押します。
STEP 2 GitHubで index.html を開き、右上の鉛筆マーク（編集）をクリックします。
STEP 3 編集画面で ⌘ + F（Windowsは Ctrl + F）を押し、NEWS_DATA_START を検索します。
STEP 4 // NEWS_DATA_START から // NEWS_DATA_END までの間を選択してコピーしたコードで上書きし、右上の緑ボタン「Commit changes...」で保存して完了です！
💡 貼り付け位置のサンプル（オレンジ色の範囲を丸ごと差し替えます）
// NEWS_DATA_START
const defaultNewsData = [
    { id: 1, date: '2026.11.20', ... },
    ...
];
// NEWS_DATA_END
